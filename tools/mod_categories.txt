# MOD tag | category | what it is
# The tag is the text after "MOD: " in a code comment, up to " - ", "(" or ".".
# Categories:
#   F  fix: the port behaves (or looks, or sounds) as the original game does
#   N  non-vanilla: a change from the original game outside the ragdoll module
#      (an improvement, a new option, or a bug of the original game fixed)
#   R  ragdoll / physics: the ragdoll module, accurate collision and the
#      gameplay built on them
# make_release.sh uses this table to mark each file in CHANGED_FILES.txt.
#
